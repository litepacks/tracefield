# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The maintainers of `tracefield` take security seriously. If you discover a vulnerability or security issue, please do not open a public issue.

Instead, please report it privately:
1. Open a **Private Security Advisory** on the GitHub repository.
2. Provide detailed reproduction steps and any proof-of-concept scripts.

We will review the report, acknowledge receipt within 48 hours, and work on a patch as quickly as possible.
